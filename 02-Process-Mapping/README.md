# Process Mapping

This section documents the current-state and future-state processes for the Cape Learning Institute (CLI) Student Support Management System case study.

The process mapping analysis focuses on understanding how student support requests are currently handled, identifying stakeholder needs, analysing bottlenecks and pain points, and designing an improved future-state process.

## Objectives

The process mapping analysis aims to:

- Document the current student support process.
- Identify the people involved in the process.
- Identify process inputs and outputs.
- Identify bottlenecks, pain points and inefficiencies.
- Understand stakeholder needs within the process.
- Develop an improved future-state process.
- Demonstrate how process improvements are connected to the identified business requirements.

## Case Study Note

This is a fictional Business Analysis portfolio case study based on simulated stakeholder findings. No real stakeholder interviews or observations were conducted.

The process analysis is intended to demonstrate practical Business Analysis techniques, including current-state analysis, future-state modelling, stakeholder analysis and process improvement.
